# Student Hub release scope

The production Student Hub is the baseline. Retain all existing routes, tools, data and account restrictions. Treat the Claude tablet app in hafarouk/Velthon-Student-Hub as read-only. Keep a disposition for every capability: covered, partial, missing, or conflicting.

| Area | Deliver and verify |
|---|---|
| Design | Navy and gold, light typography, distinct School and University identities, compact tablet and phone layouts, large e-ink writing surface, accessible controls. Remove the separate offline mode and mode selector while preserving student data. |
| Daily work | Daily plan, exam countdowns, due cards, resume shortcuts, mood and energy, optional quotes and Bible verses, challenges and study progress. Preserve official course program suggestions, manual entries, calendar and agenda. |
| Writing | Preserve zoom, pressure, L-shaped toolbar, page curl, OCR, shapes, pen tools, pictures, tables, export and autosave. Page overview, bookmarks and text search are live. Compare PDF page annotation, note-linked audio, zoom window, left-handed controls, sticky notes, answer tape, reusable elements, gestures and autosave folders. |
| Reading and study | Compare reader highlights to cards, source-based answers saved as notes or cards, review scheduling, deck CSV, mind maps, explain-it-back, weak-topic feedback, search and PDF/Office extraction. Preserve recording, playback, OCR, media and local study tools. |
| School and university tools | Compare course detail, grade forecasts, essay and citation tools, graphing, pronunciation, research, applications and office hours. Compare school reading logs, spelling, times tables, homework photos and teacher notes. |
| Collaboration | Preserve voice and screen sharing. Compare individual messages, moderated group discussion, task boards, and parent/tutor progress sharing. Enforce membership, access and consent on the server. |
| Preferences | Compare wellbeing and movement reminders, screen-time controls, accessibility, evening mode, account security and privacy dashboard. Preserve English, French and Spanish and audit additions in all three. |
| Android | Ship an APK with the app interface packaged inside it. Share the design and core logic with the web app. Test native microphone, transcription, camera, OCR, file picking, secure storage, reminders and sharing. |
| Access | Keep restricted existing accounts and free tools. Public registration and paid plans conflict with current requirements. Preserve consent receipts and 15-minute temporary audio handling. |
| Verification | Audit all original and added functions. Run phone and tablet emulator checks, then physical stylus, microphone and camera checks. Record evidence, fix regressions, and verify backups before migrations. |

## Review branch

This branch styles the actual workspace. It preserves markup and feature routes. It does not claim to implement the remaining gaps or replace the launcher APK. Compare this branch on desktop, phone and tablet before merging.
